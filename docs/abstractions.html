Abstractions

SOP-Lang abstractions make reusable logic and structured entities first-class parts of the dependency graph. This section groups the chapters dedicated to macro expansion semantics, JavaScript-defined commands, context-bound parameter binding, and object-style modelling through Complex Types.

Chapter Structure

Macros and JSDEF documents reusable command blocks, expansion behaviour, return semantics, and JavaScript bridging. Complex Types documents the new and lookup object surface and links to type-specific chapters.

The detailed type chapters are: Document Type, Table Type, Set Type, Workflow Type, Chat Type, Form Type, and Folder Type. Each chapter includes creation syntax, interaction methods, and reactive behavior notes.
