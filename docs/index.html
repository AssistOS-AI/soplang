SOP-Lang Current Specifications

SOP-Lang is a Domain-Specific Language (DSL) designed to be the glue of the ACHILLES IDE, orchestrating complex agent behaviours and build processes. Its parser and runtime are developed as a back-end concern, while complementary UI tools such as variable-state visualisation are developed in UI layers.

This documentation describes the current state of SOP-Lang as implemented in this repository. The material is sectioned into pages, but the writing style and conceptual order remain aligned with the original specification text.

Recommended order: Foundations & Syntax → Assign, Alias, Await → Math & Conditionals → Macros & JS Logic → Built-in Objects → Full Command Catalog.

Quick Start: Reactive Thinking

In SOP-Lang, you don't call functions; you define variables that stay up-to-date automatically.

@name := "World"
@greeting := "Hello, " $name

# If @name changes elsewhere, @greeting re-evaluates instantly!

Design Philosophy

SOP-Lang prioritizes Prompt Engineering. Variable markers like @ and $ are chosen to avoid conflicts with natural language, making the scripts easy to read and write alongside LLM instructions.

It is designed to interoperate with containerized agents and reactive UI layers, providing a stable execution model for non-deterministic AI tasks.
