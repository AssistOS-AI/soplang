Runtime

This section groups the command surfaces and execution-model details that define current SOP-Lang runtime behaviour. It also keeps the future-work chapter connected to the same runtime branch, so roadmap topics stay attached to the implementation context they evolve from.

Chapter Structure

Runtime Commands is the catalog page for the command surface. Each command then has a dedicated detailed chapter with syntax, small examples, and behavior notes grounded in src/ and tests/.

The command chapters are: def / define, prompt, form, new and lookup, overwrite, file, best, and currentDocId and import.

Future Work keeps the ongoing design directions visible, including integration priorities with Ploinky and orchestration interfaces used through AchillesAgentLib.
