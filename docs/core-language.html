Core Language

SOP-Lang Pipeline defines a reactive and declarative command model in which each command defines one variable and is re-executed when dependencies change. The chapters in this section cover variable syntax, scoping through documents, foundational command patterns, and expression-level control flow.

Chapter Structure

Language Foundations introduces the central command construct, variable markers, scopes, and graph-level behaviour. Assign, Alias, Await details basic command composition, inter-document symbol binding, and explicit dependency triggers. Expressions and Conditionals covers boolean and numeric expressions, branching, sub-commands, guarded execution with ?, and forced execution with !.
